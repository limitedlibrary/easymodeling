# 簡単モデリング

設定を変えるだけでキャラクターの形と配色を調整し、Blenderへ持ち帰れるブラウザ用ツール。

## 今回のゴール

標準のちびキャラを使って「設定でどんな変化を作れるか」を確認できる操作可能な試作を完成させる。高品質なキャラクター制作全般を初版で実現することは目標にしない。

## シリーズの方針

- 単体で完結し、ユーザーによる素材の事前準備を必要としない。
- 将来は他の簡単シリーズや自作素材と任意に組み合わせられる。
- Blenderで続きを編集できる書き出し経路を維持する。

## 初版の仕様

- HTML/JavaScriptベースのブラウザツール。日本語UI。PCを優先し、狭い画面でも設定を操作できる配置にする。
- プログラム生成の標準ちびキャラを同梱する。頭・顔・髪・胴体・腕・脚を備える。
- 頭の大きさ、胴体の長さ・幅、腕と脚の長さ、髪の長さをスライダーで調整する。
- 肌・髪・服の色を変更する。
- 変更は即座に3Dへ反映する。接続位置を追従させ、足が床に接するようにする。
- 視点回転・ズーム・正面へ戻す操作と、設定初期化を用意する。
- 編集設定をバージョン付きJSONで保存・読み込みできる。不正な入力では現在のモデルを壊さずエラーを表示する。
- キャラクターのみをGLBに出力する。床・背景・確認用ライトは含めない。
- パーツ名と配色を保持し、Blenderで個別編集できる構造にする。
- 外部ライブラリを使う場合はバージョンを固定し、必要なライセンス表示を残す。起動に通信が必要ならREADMEに明記する。

## 今回の対象外

ボーン、ウェイト、アニメーション、自由な頂点編集、外部モデル読み込み、多数の髪・衣装プリセット。GLBは形状編集用であり、そのまま自然に動かせるモデルを保証しない。

## 完了条件

1. 素材を追加せず標準キャラが表示される。
2. 各設定の変化が分かり、最小・最大の設定で接続が大きく破綻しない。
3. 設定初期化、JSON保存と復元が動く。
4. GLBを書き出せる。可能ならBlenderで形状・色・パーツ分離を確認する。未検証なら明記する。
5. 起動方法・確認結果・制限事項をREADMEとPRに残す。
